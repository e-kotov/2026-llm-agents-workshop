WORKSHOP INFORMATION (FOR INTERNAL ADVERTISING)

Beyond the Chatbox: LLM Coding Agents for Research


ABSTRACT

This interactive full-day tutorial and workshop provides a practical introduction to using large language models (LLMs) in coding agents for research work. The session focuses on how to go beyond the simple back-and-forth with standard LLM chatbots. Instead, participants will learn how to leverage LLM coding agents to improve productivity, augment skills in computational reproducibility and code quality, track versions with Git, and automate complex research tasks including initial project setup, research work, data analysis and visualisation, and drafting grounded verifiable research reports and other outputs. Participants will learn to treat research projects more like software engineering and approach them with a mindset of optimizing the review and verification of the results rather than checking every line of analysis code.

Unlike many educational materials in this field, this workshop directly addresses the risks and potential vulnerabilities that novice users might expose themselves to by using coding agents blindly. We will cover key security risks associated with agentic systems, including data leakage—a critical concern when working with sensitive survey data—unsafe code execution, and unintended modifications to analysis code and research materials. To mitigate these risks, we will introduce accessible strategies such as containerization, sandboxing, and workflow isolation.

Participants will see how the agents themselves can assist in setting up and using these protective tools to improve transparency and reproducibility. The workshop combines short demonstrations with hands-on, applied examples. Participants are encouraged to bring their own projects or ideas to explore how LLM agents can be integrated into real research workflows. For those without a specific project, guided exercises and example tasks will be provided.

This session is designed as a hands-on learning environment for researchers at all levels of technical experience (from beginners to advanced users) who want to use LLM agents more effectively, safely, and transparently in their work.

No prior experience with coding agents is required, though some basic familiarity with LLM chat interfaces and capabilities is welcome. Some experience with scripting or data analysis workflows is helpful but not essential. Examples will be centered around R and Python, but no prior knowledge of either language is a requirement.
